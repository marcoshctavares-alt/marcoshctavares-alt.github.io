Quem Sou

Código que cresce como planta

Sou Marcos, desenvolvedor de software generalista. Gosto de entender um sistema por inteiro — do banco de dados à interface — porque acredito que um bom produto se parece com um jardim: raízes, caule e folhas precisam trabalhar juntos para florescer.

Observo como a natureza resolve problemas: raízes que se adaptam, galhos que encontram a luz, ecossistemas que se equilibram. Levo essa curiosidade para o dia a dia, aprendendo rápido, transitando entre tecnologias e escolhendo a ferramenta certa para cada desafio.

Fora das telas, você me encontra tomando um bom café e procurando a próxima coisa para estudar.
